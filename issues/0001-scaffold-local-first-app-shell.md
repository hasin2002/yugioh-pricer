# Scaffold Local-First App Shell

## What to build

Create the initial local-first application shell for the Yu-Gi-Oh card pricing app. The shell should establish the Next.js, tRPC, Drizzle, and SQLite foundation, a minimal desktop Review Client home route, and a testable project structure that later slices can extend.

## Acceptance criteria

- [ ] A Next.js app runs locally with a desktop home page.
- [ ] tRPC is wired for a trivial typed request/response path.
- [ ] Drizzle and SQLite are configured with an initial migration flow.
- [ ] The app has a repeatable local development command.
- [ ] The app has a repeatable test command with at least one passing smoke test.

## Blocked by

None - can start immediately.
