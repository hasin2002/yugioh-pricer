# Final UX/Error Pass

## What to build

Perform a human-reviewed final pass over the desktop Review Client and iPhone Capture Client. Tighten dense dashboard layout, status copy, empty states, troubleshooting messages, stale/unpriced indicators, and cross-device workflow clarity.

## Acceptance criteria

- [ ] Desktop home page is operational and not marketing-style.
- [ ] Active Pricing Session layout clearly shows Session Estimated Value, stale indicators, counts, QR/join link, Successfully Scanned, and Requires Review.
- [ ] Capture Client remains capture-first and does not expose desktop review complexity.
- [ ] Camera, capture, pricing, and connection errors are actionable.
- [ ] Stale Price, Pricing Issue, Unpriced Item, and Manual Price states are visually distinct.
- [ ] iPhone Safari capture workflow is manually verified.
- [ ] Desktop live session workflow is manually verified.
- [ ] Final UX review confirms no major text overlap or cramped controls on target desktop/mobile sizes.
