# Search And Filters

## What to build

Add collection and session search/filtering across the fields needed to find cards and unresolved work. Default views should focus on active, non-archived, collection-contributing data while allowing archived and review data to be included.

## Acceptance criteria

- [ ] Collection search covers card name, Set Code, rarity, condition, session name, and notes.
- [ ] Search defaults to active/non-archived collection records.
- [ ] The user can include archived-session records in search.
- [ ] The user can filter to Review Items.
- [ ] The user can filter by Disposition.
- [ ] The user can filter by Storage Location where present.
- [ ] Review Queue default view excludes archived sessions, with an include-archived option.
