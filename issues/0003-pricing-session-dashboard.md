# Pricing Session Dashboard

## What to build

Build the desktop home/session dashboard for managing durable, resumable Pricing Sessions. The home page should let the user create, resume, rename, archive, unarchive, and delete sessions while showing recent sessions, archived state, and basic session review counts.

## Acceptance criteria

- [ ] The user can create a Pricing Session with an automatic editable name.
- [ ] Every Pricing Session remains resumable.
- [ ] The home page shows recent sessions and a prominent continue-last-session action.
- [ ] The user can archive and unarchive a Pricing Session.
- [ ] Archived Sessions are excluded from default session views and Collection Estimated Value placeholders.
- [ ] The user can delete a Pricing Session after confirmation.
- [ ] Session Review Count is displayed for each session.
